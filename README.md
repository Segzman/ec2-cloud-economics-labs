# EC2 cloud economics labs

Two Streamlit apps using the supplied educational EC2 dataset.

- `lab3_dashboard.py`: specifications, filters, EDA charts, costs, and export.
- `lab4_regression.py`: pricing statistics, boxplots, IQR outliers, exact family comparisons, and linear regression.

Install `requirements.txt` and run either entry point with `streamlit run`.
The prices are from the dataset and are not live AWS quotes.
